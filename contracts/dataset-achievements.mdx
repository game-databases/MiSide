## Emission rules

1. Deterministic full rewrite; rows sorted by `registry_index`; UTF-8 / LF /
   compact separators.
2. Locale cells derive from the 34 client locale dirs mapped to BCP-47
   (spec §Locale strategy mapping table). `relinks/locale_availability.jsonl`
   (P1 relink stage) does not exist yet; this emit measured each locale's
   `Achievements.jsonl` directly and ledgered the dependency. Re-drive from
   the P1 ledger once it lands.
3. `global_percent` and `captured_at` stay machine-plane; user surfaces show
   rarity bands + buildId only.
4. Count reconcile FAIL-FASTs the emit: registry size == per-locale line
   count == 26 (AC-A1).

## Registry multiplicity fact

A `DataAchievements` component exists in **48 containers** (one per scene/assets
container plus the canonical `resources.assets`). The level6 clone was
spot-checked field-identical to the registry. Only `resources.assets`
is consumed; the census lives in `emit-ledger.jsonl`.

## Deviations from the illustrative spec shapes (deliberate)

1. Output family is `extracted/data/achievements/` (arbiter residue (a):
   single family name chosen by the orchestrator brief), not
   `extracted/datasets/`.
2. Schema drafts ship as these MDX contracts (field/type/source/join/
   nullability), not `contracts/*.schema.json` — the B-2 write scope names
   the two contract docs; JSON Schema can be generated from them later.
3. `steam.global_percent` is populated from a live keyless capture this pass
   (spec deferred it; the page fetch succeeded), stamped with `captured_at`.
4. `type_tag` assignments are curated as the spec's schema requires; the
   client has no such field. Per-index rationale:
   minigame = Penguin Piles TV game (3), fly console idle win (5,
   `[inferred]` semantic gloss), spec-labeled bodies Spaceracer (15),
   Snake (18), Quadrangle (20, 21), Hetoor (22, 23);
   ending = the three Part-B anchors; collectible = the two set-completion
   targets; meta = all-others (25); missable = one-shot interactable (16).
5. `icon.official_url` added (Steam CDN icon URL) as an interim display
   source until the client-bytes re-export lands; flagged per-row so the
   swap is mechanical.
