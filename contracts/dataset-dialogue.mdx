## Identity scheme (load-bearing)

- Node id = `<container>:<Class>#<truePathID>`, e.g.
  `level9:Dialogue_3DText#20023`. The PathID is the component's **real
  serialized PathID read from the scene file itself**, not the mb-dump
  filename suffix — AssetStudioMod's `_#N` suffix is a tool-internal id
  space that matches nothing in the ASL crosswalk (verified: no `#12799`
  exists in `level9.xml`). Embedded cases/entries use path-scoped ids
  (`...#pid/case/i`, `.../text/g/t`, `.../line/g/l`, `.../pet-line/d`).
- The one bare-named dump file per class per container is matched to its
  true PathID by elimination against the numbered files' resolved identities;
  each such match is recorded in `_ledger/identity-reconciliation.jsonl`.
- Edge targets: `nextText` points at **GameObject** PPtrs (resolved via the
  GO→component map); `nextDialogue` points at components directly;
  UnityEvent targets classify as dialogue-node id, `component:<Type>#pid`,
  `gameobject:<pid>`, or `out-of-census-scope` (cross-file).

## Join contract — `line_index = game_index − 1`

Every pointer in this dataset converts at emit time. The spec's off-by-one
contract ([DS-3 §3.2/§3.6](../docs/specs/dataset-dialogue.mdx)) applies to ALL
four serialized index fields, and this build measured the confirmation:

| Field | Carrier | Evidence for −1 |
|---|---|---|
| `indexString` | Dialogue_3DText | max == count on 16 levels; level6 `#7124`→LD4 line 0 `"Mita?"`; boundary proof in spec |
| `stringFile` | DialogueChangerCase | level5 box (`fileQuest "Location 3"`): −1 lands case[0] (`exitButton=true`) on `"Never mind."` and every other case on a coherent question row; identity copy lands two of them on `//` comment rows |
| `indexFile` | Loc14_DialogueText | max 217 == LD14 count |
| `index` | Location18_DialogueIndex | union closes LD18 at 259 |

Range authority = **pivot EN category counts** (`GetCountString` semantics).
Per-locale tails differ in exactly 4 locales (see Locale parity below).

## Speaker model

- `ambient_line.speaker.theme` = verbatim `Dialogue3DTheme` value; `entity`
  slug resolves for 9 themes (`provisional-pending-ds1` status — alignment
  with B-1's `character_id` namespace is that dataset's curation call);
  **5 themes stay `{slug: null, status: "pending-curation"}`**: MitaKnow,
  MitaFon, White, Creepy, MitaDream (brief/D6 fence — never guessed).
- `branch_group.entries[].speaker_enum`: `player | mita` (Loc14WhioSpeak).
- `grouped_scene_dialogue.groups[].personage_ptr`: raw Location18_Personage
  PPtrs (entities land with DS-1 curation).
- `choice_case`, `quest_box`, `pet_dialogue` serialize **no speaker field**;
  the field stays null. This caps speaker coverage at 96.23% (D6 PARTIAL,
  structural ceiling — see scoreboard note).
- `voice_present` is null on every record: no serialized dialogue→audio join
  exists in the corpus (AudioDialogue is a separate carrier family); the
  linkage happens at runtime only.

## Condition hints (§3.5 honesty box)

The 328 EN `//` author-comment rows attach to the next non-blank non-comment
row of their category (previous-row fallback), verbatim, `lang: "en"`, never
rendered as speech — every hint-bearing ref of a node attaches, not just its
first. **320 of 328 ship into emitted `condition_hints`** (324 placements
over 318 nodes); the 8 whose target row no component serializes are ledgered
explicitly in `_ledger/build-meta.json` → `hint_stats.unattached_rows` with
reason + target line — never silently dropped. The reconciliation invariant
`emitted + unattached == 328` is asserted in-code and re-derived
independently by the checker. 0 text_refs land on comment rows. No predicate
DSL is claimed anywhere — branching semantics live only in resolved
`on_finish_action` calls.

## Deviations from the illustrative spec shapes (deliberate)

1. **Output root `extracted/data/dialogue/`** (brief; arbiter residue (a)
   picked the `data/` family). `graphs/`, `_ledger/` subdirs added to §7's
   six-file list for AC D5/D2 provenance.
2. **Emitter + checker parked at `data/dialogue/build/`** — write scope
   excludes `pipeline/stages/`; register there at emit-stage adoption.
3. **True component PathIDs replace dump-filename suffixes** in node ids —
   the client file is the identity authority; filename `_#N` proved to be a
   different id space.
4. **Branch forks are text-keyed edges**, not node-only references — DS-3
   §3.3 says "keyed on loc line indices"; measurement shows 10 wired forks
   target rows no node serializes. `carrier-for-index-not-found` is therefore
   NOT dangling when the row is in-range.
5. **`random_router` emits zero nodes/edges**: `Location21_DialogueRandom`
   has zero instances across all 51 containers (measured absence, not omission).
6. **Locale parity finding contradicts spec §2.1's parity claim** — kept as
   data with pivot-authoritative ranges; spec text amendment is the
   specifier's call.
7. **Quest-label categories** (`Location N`) ride their own −1 contract
   (evidence above); EN `Location 3` line 12 carries a U+FFFD outside the 7
   LD12 ledger rows — out of D4 scope, noted here for the loc layer.
