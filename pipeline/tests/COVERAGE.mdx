## Negotiation outcomes & spec observations (2026-08-24)

Resolved during bring-up, black-box via stub side channels:

1. **Asset-list mechanism (§8 verify item)** — resolved POSITIVE: `-m dump`
   tolerates `--export-asset-list xml` in the same pass; crosswalks land at
   `harvest/asset-list/<stem>.xml`. No fallback pass needed.
2. **Stale-log defense scope** — the refusal fires on pipFreeze vs
   `requirements.txt` disagreement only (exactly AC-3's letter). A WRONG
   *tool version* in an otherwise well-formed pin block does NOT refuse —
   flagged here because §S3's "stale-log defense" intent may want a
   tool-version consistency warning too. Owner call.
3. **Stage reports carry run-fact booleans** (`created:true→false`,
   `freeze_matched_before`) that flip on idempotent reruns and are not in
   `volatile-fields.json`. AC-5's text exempts "stage-report run facts", so
   the suite masks top-level booleans on `census/stage-reports/*.json`
   specifically; anything else changing is a hard failure.
4. **Measure-first probe failure fail-fasts even under `--keep-going`** —
   defensible (a failed probe cannot size the sweep budget); the LEDGER
   downgrade applies to sweep-phase containers, which the suite tests.
5. **§S2 prose vs artifact**: detect.json does not surface explicit
   ".unity3d bundles absent / no Addressables catalog" verdicts. Not an
   AC-6 item; noted for patch-day completeness if wanted later.
