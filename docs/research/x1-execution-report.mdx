### I-3 — S5 exit-policy deadlock (new)

Seven category files — **all one category, `LocationDialogue Location12`, in seven locales** (Croatian, English, Filipino, Indonesia, Serbian Latin, Slovak, Vietnamese) — are legacy single-byte encoded mid-file (CP1250 `9a`=š / `f2`=ô visible in the hex evidence) inside otherwise-UTF-8 trees. Spec §2 S5 semantics: parse continues, raw bytes hex-ledgered into `loc-jsonl.json`, **stage exits non-zero at stage end if anything was ledgered**. Under AC-3 that halts every full run before S6 — so a full `run_all` can never complete while those files ship in the client, even though the loc layer itself finished cleanly (2,203/2,210 emitted, shortfall fully explained by the ledger).

Executor handling: no §7 row covers S5, and `--keep-going` is S4/S7-only. The documented resume slice `--from art-export --to census` was used once (run B) as the fallback-shaped action — entrypoint-sanctioned, idempotent stages, no code touched. That decision needs a ruling (escalation 2).
