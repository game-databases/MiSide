## Per-axis grades

### Visual soul — 6

Tokens are right and it never reads as atlas chrome: plum field, pill
grammar, LCD machine voice, hot pink reserved for identity/actions, glow on
the focused chip, `Client build 19029065` stamp in the footer
([map-en-full.png](shots/vcmap/map-en-full.png)). But the viewer's only
self is a 480–730 px checkerboard with three floating buttons — the
schematic grid *and* the VoidWell checkerboard stack into visual mud
([map-en.png](shots/vcmap/map-en.png)), no scene title lives inside the
panel, and nothing about the panel says "map" or "MiSide room". Wikily's
equivalent panel is hand-painted parchment with 2,200+ clustered markers
([wikily-map.png](shots/vcmap/wikily-map.png)); ours is a texture. Soul of
chrome: yes. Soul of a map: not yet.

### Interaction depth — 4

What works (verified, not assumed): cold-load restore of `?scene=` +
`?focus=` + `?kinds=` ([map-en-focus-cold.png](shots/vcmap/map-en-focus-cold.png)
— select flips to the deep-linked scene, focus chip renders); `?kinds=`
rewrite on toggle; scene change pushState; zoom/reset pills ≥44 px; mobile
375 px layout without overflow ([map-mobile.png](shots/vcmap/map-mobile.png)).
What fails:

- **Filters are a no-op on the only rows shown.** Toggling `cartridge` off
  on level17 rewrites the URL and changes nothing on screen — the
  pending/granular chip rows ignore `isEnabled()`/`matchesQuery()`
  (probe: `chipCount` 14 → 14 after toggle).
- **The quicksearch LCD prints a false statement.** Typing "mita" shows
  "0 shown" directly above seven visible rows containing "Mita"
  ([map-en-level17.png](shots/vcmap/map-en-level17.png)).
- **PinPopover, provenance cell, hover-join, LockedCell: unreachable.** No
  plotted pins exist (`popover:false` in probe; `LockedCell` additionally
  gated on `bounds!==null && imageryReady`, and bounds are null ×24), so
  the borrow-ruled rich detail pane — the two-way differentiator — cannot
  fire for any user.
- **Popstate desyncs.** After Back from `?scene=level17` the URL reverts to
  bare `/map` but the select stays on level17 (probe `afterBack`); the
  popstate handler only applies fields present in the URL and never
  restores the default scene.
- **SceneSwitcher is a native select** whose 15 chapter optgroups each hold
  exactly one scene, so every group label duplicates its only option
  ("Together at Last :: Together at Last"), and the role groups print raw
  `boot/title/menu/unbound` — untranslated in RU and AR (probe:
  RU optgroups end `Без названия, boot, title, menu, unbound`).

Wikily toggles 426 markers shown/hidden instantly, opens trader sheets from
pins, and switches regions with visual buttons; MapGenie-class persistence
flaws are the one thing we avoid. On depth we are not in the same league
yet.

### Information density without clutter — 5

The one density win: per-kind counts ride the filter chips, and the
`/locations/[scene_id]` POI listing groups classes with instance counts and
an ineligible ledger (`others/ObjectItem ×15`)
([loc-level17.png](shots/vcmap/loc-level17.png)). Against that: every row
renders **twice** (status chip + SSR anchor pill, 7 + 7 on level17), the
panel itself carries zero information, no scene facts (role, chapter,
per-kind totals) appear anywhere except the select, and the locations index
is 24 identical empty cards with no facts at all
([locations-index.png](shots/vcmap/locations-index.png)). Wikily opens with
MARKERS 2,200+ / CHESTS 377 stat tiles; our /map has no summary surface at
all.

### Mobile / RTL — 7

Mobile 375 px: controls stack, no horizontal overflow, targets ≥44 px,
popover has a bottom-sheet breakpoint (unreachable in practice, but built).
RTL: `/ar/map` serves `lang="ar" dir="rtl"`, nav/controls mirror, the zoom
stack flips to the left edge via logical `end-3`
([map-ar-level17.png](shots/vcmap/map-ar-level17.png)). Deductions: Latin
LCD tokens (`awaiting-transform-stage`, `OPEN MAP`) sit unwrapped inside
RTL pills, fallback titles leak Latin class ids ("Mta", "Tetris Game",
"Games Core Main") into the Arabic page, and kind chips stay English
snake_case in all 34 locales.

### Honesty of empty/deferred states — 8

The best axis, and it beats NWG's session-only filter memory outright.
Zero plotted rows → checkerboard well, never an absence sentence; deferred
rows surface as counted chips with status in the LCD register; unplaced
profiles get an equal-height well; nothing is ever plotted at a faked spot
(bounds stay null; imagery only over calibrated bounds); buildId prints
once in the footer. Deductions: the "Filter pins" input renders on scenes
with zero filterable rows ([loc-level0.png](shots/vcmap/loc-level0.png)) —
a control that cannot work is noise, not honesty; and the zero-marker
scene page is an undesigned empty (empty art well + empty panel + a filter
box), failing design-standard §5.2 "designed compositions".
