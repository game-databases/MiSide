### Design guidance bound into the fixes

- **F3 mechanism (ruled, one option picked): NEW FROZEN SEED.** T0 gains a
  curated input `extracted/data/build/tracker-exclusions.seed.json` (schema
  `miside.tracker.exclusions.seed/1`, buildId 19029065) whose rows carry
  `{class, count, basis, source_ref}` for `notes` (160), `wiki_only_minigames`
  (4, CAR-6 titles enumerated), `cut_family_dumps` (48, Metroidvania family);
  the seed joins T0's byte-freeze set. Because `notes` IS derivable, T0
  additionally re-derives it from frozen `world_documents.jsonl` and aborts
  naming the class on any seed≠derivation mismatch — belt-and-braces that
  keeps the seed honest without coupling the gate to prose files
  (missingdata.md churn) or violating the tier-4 no-row policy.
  Freeze-set-widening is REJECTED: it cannot recover wiki-only ×4 (absent by
  policy) and reduces the gate to string-parsing evidence locators.
- **F4 shape:** `ItemRecord` gains optional `won?: boolean` + `wonTs?: number`
  NOW, while the installed base is zero — envelope stays `v:1`, no migration
  ever needed (O3 intact: the field ships before sync, so enabling UI later is
  additive). Merge extends to per-axis LWW (`done` orders on `ts`, `won` on
  `wonTs`, axes independent); non-minigame sets never write the fields; codec
  round-trips them like `tomb`. View D v1 tracks *played*; the won toggle is
  schema-reserved for the revealer/logic-layer landing (non-goal bullet).
- **F5 tiebreak (ruled):** equal `ts` ⇒ `done=true` beats `done=false`;
  records equal on both `ts` and `done` are semantically interchangeable —
  merge declared idempotent there. Executor-independent, completion-preserving
  (a tie can never silently un-check), unit-provable today. All "local wins"
  language struck. Suite split: UNIVERSAL laws (envelope validation, drift
  preservation, deterministic merge, codec round-trip) parameterized over BOTH
  adapters; ADAPTER-SPECIFIC laws named per adapter — the synchronous
  write-per-toggle spy binds LocalAdapter only; `FakeSyncAdapter` proves seam
  typing plus every universal law.
- **F1 sibling routing:** the data-contracts §3.3 one-liner is OUTSIDE this
  piece's ownership — routed to the orchestrator lane as FIX-3 below; the
  tracker fixer must not touch data-contracts.mdx.
