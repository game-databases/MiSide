## 3. Findings against the post-fix spec

### V-B-1 (MODERATE) — §3.7 misassigns `groups[]` to branch_group; grouped_scene_dialogue's payload is unlisted

Payload-key split measured over nodes.jsonl: branch_group rows (×11) carry exactly
`entries`,`forks`,`main_ptr`; **`groups` occurs ONLY on the 11 grouped_scene_dialogue rows** (which
also carry next_resolved ×11). §3.7 states "kind-payload on exactly its kind's rows — …
branch_group{entries[],forks[],groups[],main_ptr}" and gives grouped_scene_dialogue no payload at
all. Same defect class as F-6, and it would propagate into entities.json as a wrong per-kind
payload map (fails the spec's own C2/C10 intent). Fix: move `groups[]` to grouped_scene_dialogue.

### V-B-2 (MINOR-MODERATE) — §3.9 claims scene-level `chapter_name_loc/en` are "null v1"; disk has them populated ×15 / null ×9

Measured scenes.jsonl: display_name_loc null ×24 (null-v1 correct), but chapter_name_loc and
chapter_name_en are populated on **15 of 24 scenes** (15 of 20 story levels) and null on 9. SCN-8
itself — the cited ledger — says exactly this ("display_name_loc null v1 + chapters … 15 non-zero
pointers of 20 story levels"), so the spec's own citation contradicts its compression. A consumer
reading §3.9 would conclude scene-level chapter names don't exist yet when they do. Fix: pin
`display_name_loc` null v1 ×24; `chapter_name_loc/en` populated ×15 / null ×9 (SCN-8/XC-2).

### V-B-3 (MINOR) — §5 "Row shapes" attributes five numeric fields to BOTH bucket and presence rows; each kind lacks some

line_count/pivot_line_count/tail_delta/record_count/file_bytes") a parser built to the sentence
KeyErrors on both kinds. Fix: state the two shapes separately.
