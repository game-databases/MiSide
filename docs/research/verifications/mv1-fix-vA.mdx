## 4. Interpretation-call rulings

**(a) `move_point` written as BOTH classes `MitaAIMovePoint` (31) +
`Transform_Position` (71) where the arbiter named only
`MitaAIMovePoint` — SOUND, and in fact required.** Both classes carry
kind `move_point` in poi-kinds.json, so the family stays keyed
`(move_point, …)` with a closed two-class list — precisely the law's
shape. The arbiter's own binding rules (closed class lists; counts
recomputed at emit from poi-kinds.json + poi.jsonl; joint coverage of
every eligible class; Σ=709) make the single-class cell untenable:
`MitaAIMovePoint` alone measures 31, not 102, so keeping only it would
break three higher laws at once to preserve an evidence-cell shorthand.
The fixer kept the arbiter-fixed axis (family_id), kind, and row total
identical and corrected only the class enumeration to measurement —
adding a 12th family or re-homing the class would have exceeded the
permitted delta. Faithful application, not deviation.

**(b) `minigame_access` emission counts confined to
`placement_families[]` (disposition "emitted" via that list) so AC
MV-0.4(c)'s Σ does not double-count across two families sharing one
class — SOUND.** The arbiter's ruling simultaneously puts minigame
carriers in `placement_families[]` (its point 3 names them) and the two
minigame families' poi_rows inside the 709 partition (its own 11-row
table) — co-holdable only if poi-row accounting lives in
pending_families while marker-emission accounting lives in
placement_families, which is exactly what the spec writes
(:280–284: "each marker row's emitted count appears in exactly one
list, keyed by its source"). Double-counting is then structurally
impossible in (c): expected reconciliation 21 (flash-taker, pending) +
11 (profiles) + 38 (carriers) = 70 = markers data-row count at emit.
The shared-class residue is handled at the correct granularity by AC
MV-0.4(b)'s "container-scoped where a family declares a scope"
row-level disjointness, and the spec flags that reasoning openly under
the table (:303–306). Phrasing accepted.
