## Step 5 — Localization sanity: PARTIAL (store confirmed; plan corrections)

### Location correction

The loc store is **at game root**: `A:\...\MiSide\Data\Languages\` — a
sibling of `MiSideFull_Data\`, *not* inside it. Anything reading
`MiSideFull_Data\Data\Languages` finds nothing (verified: that path does
not exist). [toolchain.md §4](../../toolchain.md#4-localization)'s
`<Data root>` placeholder must resolve to game root in the pipeline spec.
Same tree holds `Data\Custom\` (character templates: `New (Sample)` +
`Original`, each with Body/Cloth/Colors/Face/Hair.png) and
`Data\LanguagesVoice\`.

### Counts measured

- Locale dirs: **34** (list matches toolchain.md exactly).
- Total txt: **2,210** ✓ matches toolchain.md.
- Files per dir are **not uniform ~66**: min 64 (Arabic (Egyptian),
  Belarusian), max **76 (French)** — the category set itself differs per
  locale. Join logic must tolerate missing categories, not assume a fixed set.
- Categories seen in English: Achievements, AlternativeName, Badwords,
  Clothes, CoreSoft, Location 1–14+19, LocationDialogue Location1–20,
  LocationHint Location1–20, LocationHintKey Location General, Menu,
  MiniGame CarSpace / MakeManeken / Shooter, Names, Personages,
  TelevisionGames, Translation (+ `Textures/` dir).
- Line-based plain text confirmed. Heads (first lines):
  - EN `Achievements.txt`: `Clabber` / `Creak in the Dark` / `Dead juice` /
    `Penguin Conundrum!` / `Safe of life` / `The fly's victory`
  - RU `Achievements.txt`: `Кислое молоко.` / `Щелчок тьмы.` / `Мёртвый сок.` /
    `Пингвинобеда!` / `Сейф жизни.` / `Победа мухи.`
  - EN `MiniGame CarSpace.txt`: `You've finished!` / `Position` /
    `Coins collected` / `Invasion` / `Defeat the boss`

### Gotcha discovered: no trailing newlines

`wc -l` reports `Achievements.txt` = 25 lines in EN/RU/FR, but the file has
**26 real lines** — no trailing `\n` (byte check: 414 B, 26 non-empty
split-parts, ends-with-newline false). The MonoBehaviour array has exactly
26 entries (`lineTranslate` 0–25). Any pipeline counting newlines instead
of split-lines undercounts every category file and silently shifts joins.

### Per-locale textures

Global: **777 png + 3 psd** ✓ matches toolchain.md. But subsets differ per
locale: English/Russian/French Textures = 26 png each, Japanese = 20 png.
Per-locale art sets cannot be assumed uniform.

## Deviations from toolchain.md (consolidated)

1. **Loc store path** — game-root `Data\Languages\`, sibling of
   `MiSideFull_Data\`, not `<Data root>` ambiguous form (§4).
2. **Per-dir category counts vary 64→76** (French max), not "~66 each" (§4).
3. **Category files carry no trailing newline** — line counting must be
   split-based; `wc -l` undercounts by 1 on Achievements.txt (§4).
4. **Il2CppDumper needs `RequireAnyKey:false`** for headless runs (§2 step 1
   didn't mention it; the Git-Bash cwd gotcha was real but insufficient alone).
5. **AssetStudioModCLI arg order** — input path strictly first (§2 step 2).
6. **resources.assets dump auto-loads dependencies** (5 files total), so
   per-source attribution of dumped objects needs care when reconciling
   coverage per source file.
7. **UnityPy works on Python 3.14** — the §2 step 3 fallback clause never
   fired; pin 1.25.3.

## Risks discovered

- **R-E1-1 (P5 still open, heavier than hoped):** everything juicy dumped so
  far came from `resources.assets` (UI/minigame components). Dialogue graphs,
  location logic and endings live in `levelN` scene files — the
  `DialogueChanger`/`MitaEvent`/`Location*Controller` components will appear
  there, and level dumps will be orders larger than 993 objects. Measure one
  `levelN` before committing to a parser design (as P5 planned).
- **R-E1-2:** `DataAchievements.get` bools serialize unlock state into the
  asset (`True` on first entries) — defaults vs live state must be
  distinguished when emitting the achievements dataset.
- **R-E1-3:** per-locale category-set skew (64–76 dirs) + per-locale texture
  subset skew (Japanese 20 vs EN/RU/FR 26) — locale reconciliation needs an
  explicit present-vs-reference ledger, not an assert-equal.
- **R-E1-4:** GI cache exists only for level3 — other levels' lighting is
  elsewhere or baked; catalogue it, don't chase it.
- **R-E1-5:** audio dominates the install (28,725 ogg ≈ 1.44 GB of ~2.9 GB
  non-stream total) — first MEDIA-CATALOGUE row, offload per media carve-out.

## Implications for the pipeline spec

1. **Stage order is validated end-to-end and cheap:** venv → Il2CppDumper →
   AssetStudioModCLI typed dump → UnityPy bulk. Measured wall time for steps
   1–3 combined is under a minute of compute; the harvest stage cost is
   dominated by the level/sharedassets sweep, not tooling.
2. **Localization contract is fully derivable now** — emit
   `{locale}/{category}.jsonl` records `{category, line_index, text}` with
   split-based line counting, verbatim bytes preserved; the loader authority
   `GlobalLanguage.GetString(name, index)` pins the key; ledger per-locale
   category deltas. No code recovery needed — the join is proven from assets
   + dump.cs together.
3. **Achievements dataset ships three-way joins out of the box**
   (`steamAchievement` ↔ icon pathID ↔ loc line) — 26 rows, hard mechanism,
   `inferred:false`.
4. **Drop the custom-container contingency** (P2 closed negative); baseline =
   Unity SerializedFile corpus (2.277 GB measured) + loose `Data\` tree.
5. **Keep the Lootbound text-dump parser pattern** — the observed quirks
   (tab indent, `[N]` array indexing, typed scalars) match what toolchain.md
   promised; typing via `--assembly-folder` is mandatory and sufficient.
6. **Next probes in order:** P5 (one `levelN` object/type mix) → P3
   (`--export-asset-list xml` SharedTableData/StringTable scan) → P4 (store
   locale diff vs 34 present).
7. **Pin into EXTRACTION-LOG.md:** buildId 19029065, `VERSION 0.93L`,
   Il2CppDumper v6.7.46 (net6 zip name), AssetStudioModCLI 0.19.0.0
   (FileVersion), pip freeze above, config delta `RequireAnyKey:false`.
