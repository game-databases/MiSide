## 1. Purpose + the two governing laws

The six ACCEPTED datasets carry MiSide's *wiring* (which interaction calls which effect) but not its
*sense* (whether a condition helps or hurts, what number wins). This piece adds the missing index
plane between them: a machine-readable predicate layer that lets the Ending Condition Explorer answer
player questions ("what unlocks X?", "what does this flag gate?", "what can I miss?") **without ever
asserting more than the corpus proves**.

**Law 1 — consumes-never-derives** ([data-contracts.mdx §1](data-contracts.mdx), AGENTS rule 8):
this layer *references* existing dataset rows by id and joins them; it mutates nothing. The
DS-2/DS-4/DS-6 emitted files are frozen inputs — their sha256 must be identical before and after any
LG emission (AC-L1). New claims live here or nowhere.

**Law 2 — fail-closed polarity** (scout §3 risk, carried as LAW): the graph draws itself from
serialized data, but the bit that makes advice correct — "looking in the vent HELPS or HURTS" — lives
in stripped IL2CPP native bodies ([XC-1]). A wrong render is actively harmful in a game with missable
achievements. Therefore **every polarity statement carries a mandatory evidence class**, and unknown
polarity renders as unknown — never omitted, never inferred from narrative vibes.

## 3. Evidence law — the mandatory polarity field

Every predicate row carries:

```jsonc
"polarity": { "value": "positive" | "negative" | null,
              "evidence_class": "static-proven" | "inferred" | "fail-closed-unknown" }
```

`value:null` is legal only with `evidence_class:"fail-closed-unknown"` (or when the subject genuinely
has no direction, e.g. a pure access point). A row may not state a `value` without an evidence class;
the checker rejects any `value` paired with `fail-closed-unknown` (AC-L3).

Crosswalk to existing pack vocabulary (rows imported from other datasets keep their native fields;
`evidence_class` is DERIVED at emit time by mechanical rule, never hand-assigned):

| `evidence_class` | Pack-native equivalent | Meaning | Frontend render rule |
|---|---|---|---|
| `static-proven` | `mechanism:"hard"` / `status:"proven-hard"` | byte-verified serialized site in this build's mb-dump | stated as fact, with site locator |
| `inferred` | `mechanism:"logic"` / `[community]` attribution | cited external/community source; structure proven, sense attributed | labeled "community-attributed", visually distinct, **never styled as advice** |
| `fail-closed-unknown` | `status:"unverified-behavior"` / missingdata stubs | decision lives in stripped native bodies | explicit "unknown in this build" state; no directional language whatsoever |

Rationale for admitting `inferred` rows at all: the safe-window percentages exist today inside DS-2
emitted data as `[community]` attributions; banning them machine-side would orphan already-shipped
honest data. The guardrail (mandatory citation array + distinct render) is Q3's recommendation
([§9](#9-open-questions-for-the-arbiter-with-recommendations)); the schema is identical either way,
so an owner tightening costs one renderer line, not a migration.

## 4. Modules LG1–LG4

Dependency edges (arrow = "consumes"):

```
mb-dump (51 containers) ──► LG1 flag_instances ──┐
mb-dump + dump.cs whitelist ──► LG2 effect_calls ─┼──► LG3 predicate_records ──► explorer
existing datasets (DS-2..DS-6) ──────────────────┘        ▲
mb-dump + dump.cs [Range]/public fields ──► LG4 minigame_tunables ┘ (envelope-labeled join)
LG2 ──► relinks/flag--gates.jsonl, relinks/choice--consequence.jsonl (pure projections)
endings/branch_edges.jsonl ◄──projection-check── LG2 (read-only reconciliation, AC-L1)
```

LG1, LG2, LG4 are mutually independent and can build in parallel; LG3 runs last. Per [XC-6]
precedent, **a module is not done until its `run_all` stage is registered** — emitters land with
their pipeline stage or not at all (scout §4.1, carried as a delivery gate).

### LG1 — flag-instance registry → `flag_instances.jsonl`

Sweep all 51 containers for `Events_IntMemory` / `Events_Data` MonoBehaviours; expected universe
**384** instances (§2.1 census). Capture per instance: component class, container, component path id,
host GameObject path id + name, `int_memory_default`, and for `Events_IntMemory` the full
`_memory[]` branch table (`branch_ordinal`, `if_int`, persistent-call count) — superset of the 5
`flag_tables.jsonl` rows, which must reconcile as a projection.

Identity rule (new, fixes the ambiguity in §2.3-3): filename suffix is authoritative where present
(`Events_Data_#10760.txt` → `object_path_id 10760`); **bare-named single-instance dumps carry no path
id in the filename** (e.g. `globalgamemanagers/Events_Data.txt` sits beside suffixed siblings) — for
those, resolve identity from the harvest instance inventory; where that fails, emit
`object_path_id:null` and add the row to the identity ledger. Never fabricate a path id.

### LG2 — effect-call registry → `effect_calls.jsonl`

Corpus-wide persistent-call sweep (51 containers) with a method whitelist derived from dump.cs
signatures: `Achievement_function.AchievementGet/AchievementComplete(int)` ·
`Achievement_cloth.ClothCompleted` · `Events_IntMemory.{Set,Add,Remove,CheckEvent,CheckEventIndex}`
(+ `*Ignory` variants) · `Events_Data.EV` · `Scene_Load.StartLoad/SilentSave` ·
`World.SaveStoryMita/SaveStoryCartridge`. Each call classified
`award | flag-set | flag-query | scene-flow | cosmetic | audiovisual | dead-reference` using the same
semantics DS-2 used for `branch_edges.jsonl` (so AC-L1's projection holds). Known floors: ≥11 award
sites, ≥2 cloth sites, 18 flag edges inside ending contexts — the sweep must find at least these or
explain every miss in the emit ledger.

### LG3 — predicate records → `predicate_records.jsonl`

Joins LG1 + LG2 + existing datasets into one player-question-shaped record per unlockable subject:
26 achievements, 4 endings (+ Peaceful stub), 24 cartridges, outfits, 17 minigame access points, 19
save-point literals. Sources referenced BY ID: `achievements.jsonl` (predicate_class/status),
`achievement--award-site.jsonl`, `minigame--outfit-unlock.jsonl`, `cartridges.jsonl` (`pickup_ref`),
`minigames.jsonl` (access_medium/loader_ref/rule_evidence), `endings/*.jsonl` (conditions/windows),
`scene--save-vocabulary.jsonl`, dialogue `nodes.jsonl.condition_hints[]` (provenance strings only —
never promoted to predicates, [DLG-3]/[DLG-7]). `evidence_class` assignment is mechanical:
serialized site in evidence → `static-proven`; `[community]`/wiki-attributed citation → `inferred`;
otherwise `fail-closed-unknown`.

### LG4 — minigame tunables → `minigame_tunables.jsonl`

Serialized non-default public fields + attribute-declared ranges (`[Range(0,6)] int
enemyComplexity` on `Location4Fight`) from mb-dump + dump.cs per minigame carrier
(`CarSpace_*`, `MakeManeken_*`, `Location14_PCSnaker`, `Location17_PumpkinClicker`, `Tamagotchi_*`).
Every row is stamped `"kind":"envelope"` and asserts **no** win threshold (AC-L4). Presentation-only
keyframe dumps (e.g. `CarSpace_Money.animationFly`) are out of scope — art/presentation plane, not
rules.

## 7. Internal-only rows (never emitted to the frontend)

Rows the extraction produces but that answer **no user question** — emitted to the data plane,
flagged `"internal_only":true`, excluded from explorer surfaces (scout §4.5, carried verbatim):

1. **Dead-reference edges (×3)** — destroyed-target wiring residue ([END-4]; `CoreSkip.StopWait`
   type exists nowhere in il2cpp metadata). Index-only forever.
2. **Cosmetic (468) + audiovisual (356) effect calls (~824)** — presentation wiring; no user
   question exists. Graph-traversal fuel only.
3. **Unnamed flag instances with no joined context** — "what does flag 11272 mean?" is unanswerable
   until joined to a `prompt_loc`/dialogue context; such instances stay index-plane and surface only
   through those joins (LG3 sets `internal_only` per join outcome, not per class).
4. **Minigame tunables (LG4)** — the player question ("how do I beat CarSpace?") exists but the
   answer (thresholds) is NOT STATIC; emitting tuning curves as if they were rules would be a
   false-statement engine. Ship envelope-labeled or not at all.

Flag-query edges (×8) ride the graph as traversal structure; they are not separately surfaced.

5. **OQ-5 — explorer MVP cut.** *Recommendation: ship now on the STATIC wiring* with fail-closed
   polarity rendering (guardrails per OQ-3). The wiring is won and honest; the sense routes through
   [XC-1] later without schema change — `evidence_class` absorbs upgrades row-by-row. Holding the
   rank-1 tool for a costed native pass trades certain value for uncertain spend.

## 10. Flip paths

1. **[XC-1] native pass — owner-gated cost decision.** `il2cpp/script.json` carries every method
   RVA; a Ghidra/IDA-class decompile of `GameAssembly.dll` converts F2/F5/F6/F10 to PARTIAL-or-better.

   pending the OQ-4 scope ruling. Not scheduled by this spec.
