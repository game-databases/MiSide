## 1. Purpose + player-experience framing

MiSide gates its payoffs behind choices that serialize only their *wiring*: which
interaction fires which call. Whether a choice HELPS or HURTS lives in stripped
native bodies ([XC-1]), so half of the player-facing truth about endings,
missables, and unlock chains is structurally invisible to any guide. Competitors
answer it with prose and folklore (COMP J1: negative conditions modeled nowhere);
the corpus lets us answer it with something stronger and stranger — **every
connection, honestly labeled by how much we can prove about it**.

This tool is the session companion for a missable-heavy playthrough. It must make
that progression FEEL navigable, not read like a spreadsheet:

- **Question-first cards, not tables.** Every subject opens on its recorded player
  question (`predicate_records.question_en`: *"What unlocks \"Pat on the head!\"?"*),
  answered with the shortest honest sentence the evidence supports. One question per
  card; depth is progressive disclosure, never a wall of rows.
- **Three lenses over one graph.** *Endings* (walk the choice tree toward an
  ending), *Subjects* (26 achievements · 23 cartridges · 17 minigames · 3 outfits ·
  19 save points · 1 safe window — "what unlocks X / where do I get X"), *Flags*
  (the named flag registry: who writes it, who reads it). All three render the same
  accepted rows; nothing is joined twice.
- **Confidence is visible state, not fine print.** A proven connection, a
  community-attributed one, and an unknown one look different at a glance — and the
  unknown state still guides: it says exactly WHAT is known (the interaction exists,
  the call site is dumped, here is the container) and refuses only the direction.
  An honest "the game never tells us here" beats folklore the corpus contradicts.
- **Missability without fear-mongering.** Where the data proves a payoff is tied to
  a specific scene interaction, the card says so in machine voice; where it cannot,
  the verdict vocabulary of [§8.1](#81-verdict-vocabulary-closed-set) forbids
  "impossible"/"lost forever" claims the corpus does not back.

**Why a data-side module gates everything:** the frontend-consumes law (AGENTS rule
8, AC-L6) plus A-LL2 ruling B make the explorer live-imminent for a silent-misbind
harm class — the moment flag bindings hit the screen, a wrong id-resolution renders
as player advice. So M0′ emits a precomputed bundle and the frontend derives
nothing ([§5](#5-m0--explorer-bundle-emitter-data-side-gating-module)). No viewer
module ships behind M0′'s gating ACs (E1, E2, E10 — [§14](#14-acceptance-criteria-e1e14)).

- **Space-partitioned resolution** (ruling A): suffix-space handles
  (`flag_instances.object_path_id`, node-id host segments,

  (`effect_calls.target.*.object_path_id`, `inventory_object_path_id`,
  `host_go_path_id`) names REFERENTS. Numeric equality between spaces is measured

  undetectable until it surfaces as advice — hence D1's precomputed-joins-only rule.

And the logic-layer handoff obligation (logic-layer §10): unknown polarity renders
as unknown, never styled as advice, with OQ-3's renderer flip as the single switch
that tightens it. This spec implements that obligation; it does not reopen it.

## 5. M0′ — explorer-bundle emitter (data-side gating module)

### 5.1 Emission law

1. **Consumes-never-derives, applied to resolution** (Law 1 + D1): the emitter
   reads the eight §3 artifacts (three `logic/*.jsonl`, three
   `endings/*.jsonl`, two relinks) listed in
   [§3](#3-disk-audit--consumed-artifacts-measured) and performs ONLY projection,
   filtering, prefix normalization (§5.2), label joins, AND path enumeration over
   already-shipped rows (§8.2 `paths[]`). It resolves NO new id binding: if a
   flag↔call relationship is not in `writers/readers` ∪ `flag--gates` ∪
   `subject_ids`, the bundle records absence-of-binding (D3) — never a guess.
2. **Byte-freeze**: sha256 of every consumed file recorded before and after
   emission; mismatch aborts non-zero naming the file (AC-L5 tripwire pattern).
   The frozen set is exactly: three `logic/*.jsonl`
   (`predicate_records`, `flag_instances`, `effect_calls`) + three
   `endings/*.jsonl` (`choice_nodes`, `branch_edges`, `endings`) + two relinks
   (`choice--consequence`, `flag--gates`). (`flag_tables.jsonl`,
   `emit-ledger.jsonl`, `relink-ending-branch-edge.jsonl` are NOT consumed by
   this tool and stay out of the freeze manifest.) All eight must be
   byte-identical after the run (AC-E1).
3. **Verbatim law-carrying**: `polarity`, `status`, `evidence_class`,
   `citations[]`, `internal_only`, `sense_source`, `mode_unlocked.state` ride rows
   UNMODIFIED. The bundle adds zero new claims; its `_meta.generator` names this
   spec and the input hashes.
4. **Internal-only exclusion**: rows with `internal_only:true` and classes
   `cosmetic`/`audiovisual`/`dead-reference` never enter the graph payload; they
   enter ONLY the `_meta.exclusion_ledger` counts (AC-E10). Within tree scope that
   hides 824 presentation edges + 3 dead refs while keeping traversal connected
   ([§6](#6-tree-ui-m1m2)).
4a. **Wiring-step carrier**: wiring-step enumeration happens at EMIT time over
   the shipped rows only — entries carry EXACTLY the four whitelisted keys
   `{edge_ref, from_node, container, call_index}`; rendering is machine-voice
   locator text with NO condition language ([§6](#6-tree-ui-m1m2) chips,
   AC-E10 key-whitelist assertion).
5. **Determinism**: same inputs ⇒ byte-identical outputs (AC-S8 pattern); stable
   row ordering keyed on canonical ids.

### 5.2 Prefix normalization table (BINDING)

One table, one module (`lib/explorer/idSpaces.ts`, mirrored into the emitter so
both sides cannot drift). This discharges D6; the table is exhaustive — adding an
id form not listed here is an AC-E7 failure, and fuzzy/string-similarity matching
is banned outright.

| Prefix family | Convention | Example (from disk) | Resolves to |
|---|---|---|---|
| `logic:flag:<container>:<instance>` | bare corpus id (`flag--gates`, `flag_instances.flag_id`) | `logic:flag:level9:Events_IntMemory` | flag_instances row |
| `logic:call:<container>:<file>:<host>\|x:<field_path>:<n>` | bare corpus id (`flag--gates`, `effect_calls.edge_id`) | `logic:call:level9:Trigger_Event_#11187.txt:11187:eventEnter:6` | effect_calls row |
| `choice-node:<container>:<component>[:<tail>]` | synthetic (`choice--consequence.from`) | `choice-node:level10:DialogueChanger` | choice_nodes.node_id |
| `effect-call:logic:call:…` | synthetic wrapper (`choice--consequence.to`) | `effect-call:logic:call:level10:DialogueChanger.txt:x:buttons[1].eventClick:0` | effect_calls row |
| `logic:{achievement\|cartridge\|ending\|minigame\|outfit\|save-point\|safe-window}:<slug>` | predicate subject id | `logic:achievement:achi_slaphead` | predicate_records.predicate_id |

Normalization rules: `choice-node:`/`effect-call:` wrappers strip to their inner
corpus id for joining; `x` in a host segment means "no suffix id in the dump
filename" (matches `host_object_path_id:null`); **numeric tails inside a handle
(`…:1786`, `…#11187.txt:11187:…`) are opaque row-handle tokens** — they ride the
canonical string verbatim, are never split into standalone numeric params (D5),
and are never parsed back into arithmetic joins. They survive in URLs only inside
the slugified canonical id ([§12](#12-deep-linking--url-state-law); reading RULED
CONFIRMED — [OQ-E4](#16-open-questions-for-the-arbiter), A-EC1).

## 6. Tree UI (M1+M2)

The walk opens COLLAPSED at four ending roots (the 4 `endings.jsonl` rows) — a
player sees four doors, not 1,555 wires. Expanding an ending reveals its condition
subtree; expanding a node reveals its outgoing options as the game's own choice
pills; expanding a pill reveals the calls it fires.

Structure law:

- **Connectivity without dishonesty.** Only the 728 condition-class edges render
  as connections. The 824 presentation edges stay traversal fuel: when the only
  path between rendered nodes runs through them, the walk shows a collapsed
  machine-voice chip `+N wiring steps` (LCD register) that expands to the
  bundle's `wiring_steps[]` entries (keyed by `edge_ref`, §5.3) — a neutral
  list of call targets with NO condition language — they exist, they fire, they
  mean nothing advice-shaped.
- **Option toggles compute nothing unprovable.** Toggling a choice pill recomputes
  the reachable-verdict over PROVEN structure only (which interactions sit on the
  path). Direction-unknown branches cannot flip a verdict; they render the
  branch-fork with the UnknownState treatment and the verdict pill stays in its
  honest state ([§8.1](#81-verdict-vocabulary-closed-set)).
- **Flag nodes are first-class citizens.** A bound flag node links to its flag
  card (writers/readers from the precomputed joins). An unnamed/unresolved flag
  renders the UnnamedFlagChip — a declared state word, not a number (D2).
- **Node census floor, stated once**: 371 nodes is the SERIALIZED floor; choices
  routed purely through code do not serialize (END-6). The tree header carries
  that caveat in machine voice so nobody reads the graph as complete.

## 8. Unlock-path calculator + what-blocks-this (M4)

### 8.1 Verdict vocabulary (closed set)

The calculator answers "how do I get X / what blocks X" over precomputed paths
only. Its output vocabulary is CLOSED — pinned by
[OQ-E1](#16-open-questions-for-the-arbiter), RULED CONFIRMED by A-EC1:

| Verdict | Meaning | Render |
|---|---|---|
| `proven-reachable` | a serialized path from a scene entry to the subject exists and every hop is condition-class | gradient pill, machine-voice path list |
| `gated-by-known-condition` | path exists and passes named gates (pickup sites, save literals) | pill + gate list, each hop evidence-classed |
| `wiring-known-sense-unknown` | path exists; ≥1 fork's direction is fail-closed | pill + UnknownState forks enumerated — the honest headline answer for the six Conditions-Met prerequisites |
| `path-unknown-fail-closed` | no serialized path (code-routed choices, END-6) | pill + "not serializable in this build", never "impossible" |

There is NO `impossible`/`missed-forever` verdict: `"negative"` polarity has ZERO
occurrences this build (logic-layer §3 reservation), so the corpus authorizes no
harm-direction claim anywhere. The four verdicts are pairwise disjoint:
`proven-reachable` requires a path with ZERO named gates;
`gated-by-known-condition` requires ≥1 named gate; every evaluated path matches
exactly one.

### 8.2 Forward flow — "how do I get X"

Subject card → calculator lists every precomputed path into the subject's
predicate row (via award/cloth/pickup/access-chain condition shapes), each hop
rendered with its evidence badge. Hops are the shipped rows; the calculator
composes NOTHING (D1 — path enumeration is projection over `subject_ids` +
`flag--gates` + tree edges, computed at EMIT time and shipped in the bundle as
`paths[]`, so the frontend filters but never walks raw files).

### 8.3 Reverse flow — "what blocks this"

Ending pane → conditions block → per-condition "who writes this flag" expansion
(writers from `flag_instances.writers` / `flag--gates` inverse rows). When a
condition's flag has NO bound writer (identity unresolved), the panel renders the
absence-of-binding well: "wiring unknown in this build — the flag exists, no
serialized writer binds to it" (D3), with the identity-ledger reason class. Empty
list ≠ no blocker; it is itself a labeled state.

## 11. Design language requirements

Soul grounding: `site/src/styles/design/tokens.css` (three tiers) — the explorer
feels like the game's own mid-screen choice moment, not atlas chrome.

- **Choice pills**: options render as pill-chrome buttons riding the accent
  gradient (`--ms-accent-gradient`, radius family `--ms-radius-*`), keycap-bracket
  chip affordance — the "TAKE PILLS" precedent (T2 §3). Hot pink `--ms-accent`
  stays reserved for identity + actions (focused pill, active filter, primary
  link); never a per-kind hue.
- **Compromised paths wear corruption as STATE**: direction-unknown forks and
  unreachable-flagged entities take `CorruptionHover` (`--ms-glow-glitch`,
  `ms-vhs-drift`) pairing VHS banding + RGB split — marking the uncertain path as
  state, not decoration (T2 §4.1). It must remain readable under `prefers-reduced-motion`
  (drift loop is already gated; banding persists statically).
- **Machine voice = CRT green**: evidence classes, counts, buildId stamp, call-site
  locators render in the LCD register (`--ms-font-lcd`, VT323 rung) on
  `[data-slot="lcd-terminal"]` surfaces with `ms-scan-breathe`; body labels use
  `--ms-font-sans` ≥12 px. Evidence badges are color+word, never color alone:
  `static-proven` (signal green) / `inferred` (warm cream + citation count) /
  `unknown` (bg-2 + danger-tinted glitch border) — D4's visual distinctness made
  mechanical.
- **Surfaces**: plum stack `--ms-bg-0/1/2`, borders via `color-mix` on
  `--ms-accent-soft`. No uncited hex anywhere under `src/components` (AC-S8
  defect class); a missing axis lands in `tokens.css` first.
- **Unknown states use VoidWell grammar** (checkerboard), never captions-of-absence;
  wells equal height to filled cards (§10).
- **Motion is state**: focused pill `ms-glow-pulse`; verdict pill transition on
  recompute; nothing blinks. Hover does work everywhere (chip hover highlights its
  subtree; badge hover opens the citation popover).

## 12. Deep-linking & URL-state law

Follows the scaffold tool-input ruling (site-scaffold §3/§6:
`replaceState`, never navigation keystrokes; shareable result URLs) and the
`mapState.ts` precedent (map-viewer §6):

- **Route pair**: `/explorer` (pivot, en) + `/[locale]/explorer` ×34 — first-class
  route like `/map`, linked from the Tools index; canonical slug in sitemap:
  `ending-condition-explorer`.
- **State keys** (query params, canonical string ids ONLY — D5):
  `?lens=endings|subjects|flags` · `?subject=<canonical subject id>` ·
  `?node=<choice-node id>` · `?flag=<logic:flag:id>` ·
  `?evidence=static-proven,inferred,fail-closed-unknown` · `?kinds=<csv>` ·
  `?picked=<comma-separated picked option node ids>`.
- **History discipline**: `pushState` on lens change / subject-node-flag
  navigation (back button undoes one navigation); `replaceState` on pill toggles,
  filter changes, clears (typing never spams history).
- **Slug encoding**: canonical ids slugify verbatim (colons percent-encoded);
  a numeric tail inside a handle rides the slug opaquely and is never exposed as
  its own parameter ([OQ-E4](#16-open-questions-for-the-arbiter)).
- **Cold-load restore**: full state reconstructs from the URL alone; unknown ids
    render the not-found well naming the id class — never a silent redirect that
    could mask a broken link.
- **Integer probe rule**: a request whose params contain a bare integer where a
    canonical id is expected (e.g. `?flag=11272`) does NOT resolve; it renders the
    canonical-form help state. This is D5 made runtime-testable (AC-E8).
